# ShopEasy

A lightweight e-commerce web application built with vanilla HTML, CSS and JavaScript.

## Project Structure
```
frontend/   – UI pages
backend/    – Server-side logic & logs
```

## Setup
1. Clone the repo
2. Copy `.env.example` to `.env` and fill in values
3. Open `frontend/index.html` in a browser

## Contributing
Please branch off `main`, open a PR and request a review before merging.
